## 制限事項

- PDFの変換に時間がかかります。9件で2〜3分程度です。
  毎朝の自動実行には向かないため、必要なときに手動で実行する想定です。
- ファイル名に「見積」「発注」が含まれている必要があります。
- 1つのフォルダに同じ種類の書類が複数ある場合、どれを使うかは保証されません。
- 差額の原因は判定しません。確認は人が行います。
